# Prior Authorization: Specialty Drugs

## Scope
Applies to:
- J1745 - Infliximab infusion, per 10mg

## Requirement by plan
All four plans (PLAN001 PPO Gold, PLAN002 HMO Standard, PLAN003 EPO Bronze,
PLAN004 POS Silver) require prior authorization for infliximab and other
specialty biologic infusions without exception. This is a plan-wide policy
and does not vary by network status.

## Clinical criteria
Authorization is approved when documentation includes:
- A diagnosis consistent with an approved indication (e.g. moderate to
  severe rheumatoid arthritis, Crohn's disease, ulcerative colitis, or
  psoriatic arthritis)
- Evidence of an inadequate response to at least one conventional
  first-line therapy
- Prescribing provider is a specialist appropriate to the diagnosis
  (rheumatology, gastroenterology, or dermatology)

## Reauthorization
Ongoing infusions require reauthorization every six months. Claims for
infusions beyond the six-month authorization window without a renewed
authorization on file will be denied.

## Common denial reasons
- No prior authorization on file
- Authorization expired (reauthorization not submitted before the six-month
  window elapsed)
- Diagnosis code on the claim does not match an approved indication on the
  authorization
