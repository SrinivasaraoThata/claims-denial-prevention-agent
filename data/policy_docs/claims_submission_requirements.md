# Claims Submission Requirements

## Required fields
A claim is considered complete when it includes:
- A valid procedure code (CPT or HCPCS format)
- A valid diagnosis code (ICD-10 format) that supports the medical necessity
  of the billed procedure
- A billed amount greater than zero
- A valid provider identifier
- A date of service within the member's coverage window

## Diagnosis-procedure alignment
The diagnosis code submitted with a claim should reasonably support the
procedure billed. For example, a procedure code for a knee-related service
should be paired with a musculoskeletal diagnosis, not an unrelated
diagnosis such as a respiratory or dermatologic condition. Claims where the
diagnosis and procedure appear unrelated are flagged for manual review
rather than paid automatically.

## Duplicate claims
A claim is treated as a duplicate when the same member, procedure code, and
date of service appear on more than one submitted claim. Duplicate claims
are denied in favor of the original claim on file.

## Common denial reasons
- Missing or malformed procedure or diagnosis code
- Diagnosis and procedure combination inconsistent with medical necessity
- Duplicate submission of a previously processed claim
- Incomplete documentation supporting the billed service
